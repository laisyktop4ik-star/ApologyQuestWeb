# Шёпот сосен

Полностью локальная вертикальная демоверсия атмосферной 3D-игры для браузера на Three.js/WebGL.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`).

Production-сборка:

```bash
npm test
npm run build
npm run preview
```

## Управление

На iPhone и Android:

- джойстик слева — движение;
- свайп по правой части экрана — поворот камеры;
- `БЕГ` — ускорение с расходом выносливости;
- `E` — взаимодействие с указателем, воспоминаниями и финалом.

На компьютере:

- `WASD` — движение
- `Shift` — бег (расходует выносливость)
- мышь — камера
- `E` — взаимодействие
- `Esc` — освободить курсор
- колесо мыши — расстояние камеры

## Персонализация финала

1. Замените `public/assets/images/final-photo.jpg` своей фотографией. В браузере она доступна как `/assets/images/final-photo.jpg`. Рекомендуемое соотношение — 3:2. Изображение сохраняет пропорции через `object-fit: contain`.
2. Отредактируйте `/src/config.js`:
   - `girlfriendName` — имя;
   - `apologyText` — текст письма;
   - `finalPhrase` — финальная фраза;
   - `photoPath` — браузерный путь к фотографии;
   - `backgroundMusicPath` — путь к разрешённому аудиофайлу или `null` для процедурной атмосферы.
3. Не добавляйте реальные личные сведения в публичный репозиторий без согласия человека на фотографии.

## Архитектура

- `src/rendering` — WebGLRenderer, цвет и качество;
- `src/world` — рельеф, InstancedMesh-лес, трава, объекты и коллизии;
- `src/player` — персонаж, анимация, управление и камера;
- `src/ai` — модель медведя и конечный автомат состояний;
- `src/game` — логика квестов и контрольных точек;
- `src/audio` — процедурные звуки Web Audio API;
- `src/ui` — HUD, письмо и настройки;
- `src/assets` — GLTFLoader/TextureLoader для будущей замены процедурных моделей.

## Ассеты

Игра не использует вымышленные или нелицензионные внешние ссылки. Деревья, персонаж, медведь, декорации и звуки процедурные. `GLTFLoader` уже подключён через `AssetManager`: качественные разрешённые `.glb`-модели можно добавить позже без изменения загрузочной архитектуры.
